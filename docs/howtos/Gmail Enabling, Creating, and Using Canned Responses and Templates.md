# Gmail: Enabling, Creating, and Using Canned Responses and Templates

Gmail's **Canned Responses (Templates)** feature is a great resource for those who continually receive the same questions or comments via email and wish to use prepared responses to answer these emails. The feature must be enabled in the user's Gmail Settings before this feature can be used.

**Note:** The following steps apply only to Gmail's web application. These steps do not apply if the user is utilizing a third-party mail client such as Outlook, Thunderbird, and so on.

## Enabling Canned Responses in Gmail

The Canned Responses feature can be enabled by adjusting some features available via **Settings** in Gmail. To turn enable this feature, perform the following: 

1. Click on the **Settings** gear icon in Gmail, and then select **Settings** from the menu
2. Click on the **Advanced** tab
3. Scroll down to the **Canned Responses (Templates)** section on the page, and select the **Enable** button
4. Scroll down to the bottom of the page, and click the **Save Changes** button
    

## Creating Canned Responses

 In order to create a new Canned Response, perform the following: 

1. Compose a new message. Enter the desired text for the template in any of the message fields intended (Fields could include the **Subject**, **To** and **Email Body** fields) 

   ![sys_attachment.do?sys_id=b5278513dbfe6f08824320854b96190c](https://it-knowledge.umn.edu/sites/it-knowledge.umn.edu/files/tdxassets/img5.png)
    

2. In the email response box, click on the **More Options** button in the bottom right-hand corner

   
   ![sys_attachment.do?sys_id=5652385bdb7e2f08824320854b96196f](https://it-knowledge.umn.edu/sites/it-knowledge.umn.edu/files/tdxassets/Img2.png)
    

3. Select **Canned Responses > New Canned Response** from the menu

   ![sys_attachment.do?sys_id=601c6cdfdbf62f08824320854b9619b1](https://it-knowledge.umn.edu/sites/it-knowledge.umn.edu/files/tdxassets/img3.png)
    

4. Enter a new canned response name into the popup box field and select **OK**

   ![sys_attachment.do?sys_id=6ae2b013dbbe2f08824320854b9619ed](https://it-knowledge.umn.edu/sites/it-knowledge.umn.edu/files/tdxassets/test4.png)

    

5. The new canned response will now be available for selection via the **Canned responses** menu item.

    

## Inserting a Canned Response

 In order to use a recently-created canned response:

1. Open or compose the message that requires the canned response/template

2. Select the **More Options** button 

   ![sys_attachment.do?sys_id=d13b8d93dbb2af08824320854b9619bc](https://it-knowledge.umn.edu/sites/it-knowledge.umn.edu/files/tdxassets/img7.png)
    

3. Select the desired template under the **Insert** subsection in the menu

   ![sys_attachment.do?sys_id=113bc593dbb2af08824320854b961919](https://it-knowledge.umn.edu/sites/it-knowledge.umn.edu/files/tdxassets/img6.png)
    

4. The selected canned response/template will load into the message
    

## Deleting Canned Responses

 In order to delete any previously saved canned responses/templates:

1. Compose or open a message and click on **More Options** button

   ![sys_attachment.do?sys_id=d13b8d93dbb2af08824320854b9619bc](https://it-knowledge.umn.edu/sites/it-knowledge.umn.edu/files/tdxassets/img7.png)
    

2. Navigate to **Canned Responses** and then select the canned response that needs to be deleted under the **Delete** subheading. A popup window will come up requesting confirmation. Click **OK 

   
   ![sys_attachment.do?sys_id=08e015d3dbf6af08824320854b961907](https://it-knowledge.umn.edu/sites/it-knowledge.umn.edu/files/tdxassets/img8.png)**
    

3. The Canned Response has now been removed

 

**NOTE:** Once the name of the response has been made, it cannot be renamed. It needs to be deleted and readded again.
