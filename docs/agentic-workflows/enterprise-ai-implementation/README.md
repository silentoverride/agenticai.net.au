# Enterprise AI Implementation Prompt Kit

Source blog URL: `https://promptkit.natebjones.com/20260508_595_promptkit_1`
Folder: `docs/agentic-workflows/enterprise-ai-implementation/`

## Purpose

This kit scores your enterprise AI product against the six implementation architecture components that define whether you own a workflow or decorate someone else's model — and tells you exactly where a sophisticated buyer's consultants will kill your deal. Run this before your next enterprise sales call, not after you lose it.

## How to use these prompts

Copy the prompt into ChatGPT, Claude, or Gemini. The AI will ask you six hard questions about your product before it produces anything. Answer with what your product does today — not your roadmap, not your pitch deck, not "the model handles it." The output is a single artifact: a scorecard, a tier verdict, the questions that will end your deal, and a regulated/unregulated reality check.

## Naming convention

Document IDs use the pattern `[parent-folder]-[sequence]-v1`, where `[parent-folder]` is this prompt file's immediate parent folder, the three-digit sequence preserves the prompt order within this folder, and `v1` is the initial document version. The workflow-family code `eai` is derived from the folder name `enterprise-ai-implementation`.

## Revision guidance

When updating these prompts, increment the version number in the filename (e.g., `v1` → `v2`) and update the `Version` field in the document header. Preserve sequence numbers — they establish the intended workflow order and cross-referencing with the broader agentic workflow library.
