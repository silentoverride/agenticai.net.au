# Create The Stay Honest Review Loop

Source blog URL: `https://promptkit.natebjones.com/20260428-3x9-guide-main`
Original H2 heading: Prompt 8: Create The Stay Honest Review Loop
Document ID: `calendar-hygiene-system-008-v1`
Version: `v1`

Create my ongoing stay-honest calendar review loop.

Design:

- A 5-minute daily triage
- A 15-minute weekly review
- A 30-minute monthly pattern review

The daily triage should check today's calendar against email/messages/tasks and flag only the highest-risk mismatches.

The weekly review should score the upcoming week, fix obvious holes, and make sure priority work has protected time.

The monthly review should update my guardrails based on what happened, not what I hoped would happen.

Use this report format:

- Held up: what worked and should continue
- Broke: what broke and why
- At risk: what is likely to break soon
- Prevention: one rule or calendar change that reduces recurrence

Keep it blunt, useful, and short.
