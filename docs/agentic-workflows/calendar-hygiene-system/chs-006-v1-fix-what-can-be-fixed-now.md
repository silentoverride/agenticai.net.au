# Fix What Can Be Fixed Now

Source blog URL: `https://promptkit.natebjones.com/20260428-3x9-guide-main`
Original H2 heading: Prompt 6: Fix What Can Be Fixed Now
Document ID: `calendar-hygiene-system-006-v1`
Version: `v1`

Create a cleanup plan for the current and upcoming calendar.

Group recommendations:

- Fix now
- Draft for approval
- Needs my judgment
- Leave alone

Include:

- Focus blocks for named priority work
- Prep blocks before meetings that need preparation
- Follow-up blocks after meetings likely to generate action items
- Buffers around transition-heavy meetings
- Email/message/admin windows
- Deadline workback blocks
- Reschedule suggestions
- Decline or "can this be async?" drafts
- Recurring meeting review candidates

For every proposed change, include:

- Why it matters
- Evidence you used
- Risk if we do nothing
- Exact proposed calendar edit or message draft
- Whether it affects anyone else

Do not apply changes yet. Ask for approval as a batch, and let me approve, reject, or edit each item.
