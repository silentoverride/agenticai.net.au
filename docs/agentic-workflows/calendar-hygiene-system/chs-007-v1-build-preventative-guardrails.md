# Build Preventative Guardrails

Source blog URL: `https://promptkit.natebjones.com/20260428-3x9-guide-main`
Original H2 heading: Prompt 7: Build Preventative Guardrails
Document ID: `calendar-hygiene-system-007-v1`
Version: `v1`

Build my preventative calendar guardrails.

Use the historical patterns you found and convert them into rules for future meeting invites, deadlines, messages, and commitments.

Create guardrails for:

- Meeting acceptance
- Focus block protection
- Deadline workback planning
- Prep and follow-up blocks
- Email/message batching
- Recurring meeting decay
- Travel/setup/recovery buffers
- Personal boundary protection
- Commitments found outside the calendar

Each guardrail should include:

- Trigger
- Why it exists
- What the agent should check
- What the agent should suggest or draft
- What requires my approval

Use if-then format where possible. Example:

If I accept an external meeting over 45 minutes, then check whether there is a prep block within 24 hours before it and a follow-up block within 24 hours after it.

Also create a "do not let me do this again" list based on my actual history.
