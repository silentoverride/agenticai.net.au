# Use Computer Use For Edge Cases

Source blog URL: `https://promptkit.natebjones.com/20260428-3x9-guide-main`
Original H2 heading: Prompt 9: Use Computer Use For Edge Cases
Document ID: `calendar-hygiene-system-009-v1`
Version: `v1`

Use computer use only for the parts of my calendar workflow that structured tools cannot inspect.

Use it for:

- Calendar color/category meanings
- Hidden calendars or toggles
- Declined/tentative overlays
- Apple Calendar, Outlook desktop, booking sites, school portals, medical portals, vendor dashboards, or scheduling links
- Visual density checks where the UI conveys information not exposed by the connector
- Drafting changes when no API action is available

Rules:

- Inspect first.
- Narrate what you see.
- Do not click final submit/send/save/cancel/book buttons without my explicit approval.
- If a change affects another person, money, travel, medical, school, childcare, legal, or client commitments, stop and ask.
- Prefer drafting over applying.

Tell me exactly where computer use is necessary and where MCP/connectors are enough.
