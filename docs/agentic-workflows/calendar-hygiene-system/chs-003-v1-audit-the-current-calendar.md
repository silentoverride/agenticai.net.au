# Audit The Current Calendar

Source blog URL: `https://promptkit.natebjones.com/20260428-3x9-guide-main`
Original H2 heading: Prompt 3: Audit The Current Calendar
Document ID: `calendar-hygiene-system-003-v1`
Version: `v1`

Audit my calendar for the last 2 weeks and the next 4 weeks.

Use my calendar connector or MCP if available. Classify events by type:

- Deep work
- Meetings
- Admin/email/messages
- Calls
- Errands
- Travel/commute
- Personal/family
- Health/recovery
- Prep/follow-up
- Tentative/placeholders
- Unknown

Classify cognitive mode:

- Maker: writing, coding, design, editing, strategy, analysis
- Manager: decisions, meetings, approvals, coordination
- Admin: email, scheduling, forms, invoices, logistics
- Social/emotional: sales, conflict, client, family, school, medical
- Recovery: lunch, breaks, exercise, decompression, transitions

Find:

- Focus starvation
- Too many context switches
- Related work scattered across days
- Meeting scatter
- Back-to-back compression
- Missing prep time
- Missing follow-up time
- Hidden deadlines
- Priority mismatch
- Recurring meeting decay
- Response thrash
- Recovery debt
- Travel/setup gaps
- Boundary leaks

Return a 0-3 scorecard for commitment capture, focus protection, context coherence, meeting quality, buffer/recovery, communication alignment, and priority alignment.

Do not change anything yet.
