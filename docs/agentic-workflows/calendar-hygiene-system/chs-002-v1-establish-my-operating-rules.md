# Establish My Operating Rules

Document ID: `calendar-hygiene-system-002-v1`

Build my calendar operating rules.

Use what you know about me, then ask only the missing questions that materially affect the audit. Separate:

- Known from memory/context
- Reasonable assumptions
- Questions you need me to answer

Cover:

- Normal working hours
- Hard personal commitments
- My top 3 priorities for the next 30 days
- Best time of day for focus work
- Meeting tolerance per day
- Maximum back-to-back meeting time
- Buffer preferences
- Email/message response expectations
- Admin windows
- Shutdown/recovery needs
- Commitments that should never be moved without explicit approval

If I do not answer, use conservative defaults and label them clearly.
