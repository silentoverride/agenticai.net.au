# Sweep Email, Messages, And Docs

Source blog URL: `https://promptkit.natebjones.com/20260428-3x9-guide-main`
Original H2 heading: Prompt 4: Sweep Email, Messages, And Docs
Document ID: `calendar-hygiene-system-004-v1`
Version: `v1`

Sweep my email, messages, docs, and task/project sources for commitments that should affect my calendar.

Use structured connectors first. Search the last 30-90 days, prioritizing recent and active threads.

Look for:

- "Can you", "could you", "will you", "please send", "following up"
- Dates, deadlines, launches, meetings, travel, appointments
- Promised follow-ups
- Prep material for scheduled meetings
- Docs that imply upcoming work
- Scheduling threads not represented on the calendar
- Client/customer/family/school/medical commitments
- Work I agreed to do but did not block time for
- Open loops where someone is waiting on me

For each finding, return:

- Source
- Commitment
- Owner
- Due date or likely timing
- Confidence
- Whether it appears on my calendar
- Recommended calendar or task action

Do not send messages or create events yet.
