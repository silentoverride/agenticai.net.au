# Consumer AI Anticipation Gap Prompt Kit

Source blog URL: `https://promptkit.natebjones.com/20260428_3x9_promptkit_1`
Folder: `docs/agentic-workflows/consumer-ai-anticipation-gap/`

## Purpose

This kit turns the article's analytical frameworks — the four problems (context, reliability, permission, judgment), the five-step trust ladder, the prosumer bridge, and the reactive ceiling — into diagnostic and design tools you can run against any consumer AI product, investment thesis, or your own life. Whether you're building, investing, or just trying to figure out what to actually delegate to AI, these prompts operationalize the insight that the breakaway consumer agent hasn't shipped because anticipation is structurally hard.

## How to use these prompts

Prompt 1 is the core diagnostic for founders and product leaders. It scores your product against every framework and returns an honest read on where you're strong and what's blocking breakout. Prompt 2 is for investors and strategists evaluating consumer AI bets. Prompt 3 is for product teams with a working reactive product who need to design the move below the reactive ceiling. Prompt 4 solves the "I don't know what to delegate" problem by auditing your actual digital life. Prompt 5 maps the full landscape using the article's framework for competitive analysis.

Run all in a thinking-capable model. Prompts 1-3 and 5 benefit from extended context windows. Prompt 4 works best with memory, calendar, and email access enabled.

## Naming convention

Document IDs use the pattern `[parent-folder]-[sequence]-v1`, where `[parent-folder]` is this prompt file's immediate parent folder, the three-digit sequence preserves the prompt order within this folder, and `v1` is the initial document version. The workflow-family code `caag` is derived from the folder name `consumer-ai-anticipation-gap`.

## Revision guidance

When updating these prompts, increment the version number in the filename (e.g., `v1` → `v2`) and update the `Version` field in the document header. Preserve sequence numbers — they establish the intended workflow order and cross-referencing with the broader agentic workflow library.
