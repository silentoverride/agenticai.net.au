# Marketing Is Splitting in Two Prompt Kit

Source: https://promptkit.natebjones.com/20260505_e5g_promptkit_1

## Purpose

Marketing now serves two audiences: humans who need to remember you, and AI agents who need to understand you. This kit provides three diagnostics pulled directly from the article — one to audit how agents read your company, one to pressure-test what humans actually remember about you, and one to evaluate whether a marketing role is set up for this new reality or just decorating a content factory.

## How to use these prompts

Run Prompt 1 and Prompt 2 together. They cover opposite halves of the same thesis — agent legibility and human memorability. Running only one gives you a lopsided picture. Start with whichever feels more urgent; the findings from one will sharpen the other.

Run Prompt 3 independently when you're evaluating a role, preparing for interviews, or building a hiring rubric. It also works flipped — if you're a leader, run it to see what a sharp marketing candidate should be asking you.

All three prompts work in ChatGPT, Claude, or Gemini. They're conversation-based — the AI will ask you questions before producing the diagnostic. The more specific your answers, the sharper the output. Vague inputs produce vague audits. That's by design.

## Naming Convention

Files follow the pattern: `{code}-[sequence]-v[version]-[h2-title].md`

- **{code}**: `msit` — derived from "Marketing Splitting In Two"
- **[sequence]**: Three-digit zero-padded number (001, 002, 003)
- **[version]**: Semantic version (v1, v2, etc.)
- **[h2-title]**: The original H2 heading, lowercased and hyphenated

## Prompt Files

| Sequence | File | Prompt | Purpose |
|----------|------|--------|---------|
| 001 | `msit-001-v1-the-agent-clarity-audit.md` | The Agent Clarity Audit | Walk a company's public surfaces from an AI agent's perspective to produce a diagnostic of what agents currently "see" |
| 002 | `msit-002-v1-the-human-memory-map.md` | The Human Memory Map | Pressure-test what a company is actually memorable for versus what it thinks it's memorable for, through a Socratic interview |
| 003 | `msit-003-v1-the-marketing-role-diagnostic.md` | The Marketing Role Diagnostic | Generate interview questions, interpretation flags, and deal-breakers for evaluating whether a marketing role is set up for the two-audience world |

## Revision Guidance

For future revisions of these prompts, increment the version number while preserving the sequence number. For example, a revised Agent Clarity Audit would become `msit-001-v2-the-agent-clarity-audit.md`. Keep the original v1 file for provenance. The sequence number is permanently assigned — new prompts added to this kit receive the next available sequence number.
