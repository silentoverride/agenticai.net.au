# Human Moats Prompt Collection

Source URL: `https://promptkit.natebjones.com/20260331-oom-promptkit-1.md`

## Purpose

This folder contains the prompt collection from Nate B. Jones's "The Five Things AI Can't Replace" Prompt Kit. The prompts help users position around durable human-value verticals and stress-test whether a product or workflow is genuinely agent-ready.

## How to use these prompts

Use the Five Verticals Positioning Audit to locate a business, product, or skill in durable human-value territory. Use the Agent-Readiness Stress Test to test whether a workflow can survive and benefit from agentic automation.

Open the relevant Markdown file, copy the full prompt into an AI assistant, and provide the context requested by the prompt. The sequence numbers preserve the source blog's prompt order.

## Naming convention

Prompt files use this scalable document ID pattern:

`hmoat-[sequence]-v[version]-[h2-title].md`

Where:

- `hmoat` = workflow family for this prompt collection
- `[sequence]` = three-digit prompt order from the blog
- `v[version]` = prompt document version, starting at `v1`
- `[h2-title]` = the prompt's H2 title converted to lowercase, URL-safe hyphenated text

## Revision guidance

For future revisions, keep the `hmoat` workflow family and the same sequence number, then increment the version segment from `v1` to `v2`, `v3`, and so on.
