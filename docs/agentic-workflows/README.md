# Agentic Workflows Prompt Collection

## Purpose

This directory contains a consolidated library of agentic workflow prompts. The library is organized into descriptively named subfolders. Each folder name communicates the prompt set's purpose, function, or intended use.

## How to use these prompts

1. Open the descriptive folder for the workflow area you need.
2. Open the prompt Markdown file matching your task.
3. Copy the prompt content into an AI assistant.
4. Provide the context requested by the prompt.

## Naming convention

Prompt files use this pattern:

`[folder-abbreviation]-[sequence]-v[version]-[h2-title].md`

Document IDs use this pattern:

`[parent-folder]-[sequence]-v[version]`

Where:

- `[folder-abbreviation]` = a short abbreviation derived from the immediate parent folder name
- `[parent-folder]` = the immediate parent folder name for the prompt set
- `[sequence]` = three-digit sequence number preserving prompt order within its immediate parent folder
- `v[version]` = prompt document version, starting at `v1`
- `[h2-title]` = the source prompt heading converted to lowercase, URL-safe hyphenated text
