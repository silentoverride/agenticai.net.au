## Naming convention

Files use the pattern `ptl-[sequence]-v[version]-[h2-title].md`, where `ptl` is the abbreviation derived from `prompt-template-library`, the three-digit sequence preserves the prompt order within this folder, and `v1` is the initial document version.

Document IDs use the pattern `prompt-template-library-[sequence]-v1`, where `prompt-template-library` is this prompt file's immediate parent folder and the three-digit sequence preserves prompt order within this folder.
