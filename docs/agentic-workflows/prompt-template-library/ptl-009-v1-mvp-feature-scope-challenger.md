# MVP Feature Scope Challenger

Source document: `/home/loki/Documents/nate/Prompt Template Library.md`
Original heading: 9. MVP Feature Scope Challenger

**Use Case**: Cut scope and challenge assumptions during early product planning.

**Prompt**: "Here are the features I think I need to build for this MVP. For each one, ask: 1\) Is it essential to solving the core problem? 2\) Could we ship without it? 3\) What would we learn by excluding it first? Then summarize the must-haves only."

**Why It Works**: Forces trade-offs, prioritization, and clarity.
