# Arbitrage Reinvention Prompt Collection

Source URL: `https://promptkit.natebjones.com/20260328-uqb-promptkit-1`

## Purpose

This folder contains the prompt collection from Nate B. Jones's "The Reinvention of Arbitrage" Prompt Kit. The prompts help users audit where arbitrage opportunities remain as AI changes markets and map career gaps created by shifting leverage points.

## How to use these prompts

Use the Arbitrage Audit to analyze a market, product, workflow, or opportunity space for remaining edge. Use the Career Gap Map to examine how your role or career path changes as AI compresses older forms of advantage.

Open the relevant Markdown file, copy the full prompt into an AI assistant, and provide the context requested by the prompt. The sequence numbers preserve the source blog's prompt order.

## Naming convention

Prompt files use this scalable document ID pattern:

`arb-[sequence]-v[version]-[h2-title].md`

Where:

- `arb` = workflow family for this prompt collection
- `[sequence]` = three-digit prompt order from the blog
- `v[version]` = prompt document version, starting at `v1`
- `[h2-title]` = the prompt's H2 title converted to lowercase, URL-safe hyphenated text

For future revisions, keep the `arb` workflow family and the same sequence number, then increment the version segment from `v1` to `v2`, `v3`, and so on.
