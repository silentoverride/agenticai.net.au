# Evaluation Corpus

## Overview

This corpus validates the assessment pipeline's quality metrics. It contains
5 reports generated by the pipeline with human quality annotations. The corpus
answers: "Do gate scores correlate with human quality judgments?"

## Annotation Dimensions

Each report receives scores on 7 dimensions aligned with gate criteria:

| Dimension | Scale | What it measures | Gate alignment |
|-----------|-------|-----------------|----------------|
| **evidence_grounding** | 1-10 | Do claims trace to transcript evidence? Are numbers sourced? | QW-E1, QW-E3, RR-A0, RR-A1 |
| **recommendation_credibility** | 1-10 | Are Quick Wins specific and implementable? Tools correctly cited? | QW-E2, RR-TC1-3 |
| **client_specificity** | 1-10 | Would the swap test fail? Is the report about THIS business? | QW-A1, MP-A1, RR-T3 |
| **financial_honesty** | 1-10 | Is the arithmetic chain replayable? Hourly rate stated? | QW-E3, MP-E1, RR-T4 |
| **tone_communication** | 1-10 | Appropriate register? No alarmism or overselling? | RR-Q3, RR-T6 |
| **safety** | 1-10 | No regulated advice? No over-promises? PII handled correctly? | QW-R1/R2, RR-S1-3 |
| **overall_quality** | 1-10 | Holistic: would you deliver this to a paying customer? | Composite |

### PBW (Pretty-But-Wrong) Pattern Flags

Binary flags for common failure modes:

| Flag | Description |
|------|-------------|
| `generic_platitudes` | "As a growing business..." language survives swap test |
| `tool_worship` | Recommends AI tools without solving a real problem |
| `missing_real_pain` | Top transcript issue ≠ top recommendation |
| `scale_mismatch` | Enterprise tools for small business or vice versa |
| `buzzword_padding` | AI buzzwords without concrete tools |
| `automating_chaos` | Recommending automation when processes aren't consistent |
| `never_rule_violated` | "Will save", "your competitors", regulated advice, <30min savings annualized |

## Corpus Summary

| Report | evidence | credibility | specificity | financial | tone | safety | **overall** |
|--------|----------|-------------|-------------|-----------|------|--------|-------------|
| Harbour Workflow Co | 7 | 8 | 6 | 6 | 8 | 9 | **7** |
| Lorie Test Business | 5 | 6 | 4 | 5 | 7 | 9 | **5** |
| Deck Verification | 6 | 7 | 7 | 6 | 8 | 9 | **7** |
| Marketing Agency v1 | 9 | 9 | 9 | 5 | 8 | 9 | **8** |
| Marketing Agency v2 | 8 | 8 | 9 | 7 | 8 | 9 | **7** |
| **Average** | **7.0** | **7.6** | **7.0** | **5.8** | **7.8** | **9.0** | **6.8** |

### Key Patterns

1. **Safety is uniformly high (9.0 avg).** No report contained regulated advice or over-promises. The pipeline is good at not being dangerous.

2. **Financial honesty is the weakest dimension (5.8 avg).** Every report assumes an hourly rate without stating provenance. The Marketing Agency v1/v2 inconsistency (same business, different hourly rate across generations) is the most concerning finding.

3. **Client specificity varies most (4-9 range).** Generic service businesses get generic reports. Specific businesses (marketing agency with named team size, concrete pain numbers) get specific reports. The pipeline's quality is gated on intake quality.

4. **No PBW patterns detected in any report.** The pipeline doesn't produce buzzword-padded, tool-worshipping, or scale-mismatched recommendations. This is a strong positive signal.

### Inconsistency Finding

Report 4 and Report 5 were generated from the same transcript (Test Marketing Agency). Key differences:

| Field | v1 (Report 4) | v2 (Report 5) |
|-------|---------------|---------------|
| Hourly rate | $25/hr | $50/hr |
| Weekly value | $250 | $500 |
| Annual value | $13,000 | $26,000 |
| Net annual value | $12,100 | $24,920 |
| Fireflies.ai price | $15/mo | $25/mo |
| SaneBox price | $7/mo | $15/mo |
| Design QW hours saved | 6 hrs | 3 hrs |
| Email QW hours saved | 4 hrs | 5 hrs |

The net annual value **doubled** between runs for the same input. This means:
- The pipeline is not deterministic across runs
- Gate evaluation against a specific report won't catch inter-run variance
- A customer who got v1 would get significantly less value claim than v2

**Recommendation:** Add inter-run consistency as a pipeline quality metric. The evaluation corpus should include paired runs of the same transcript to measure variance.

## Usage for Metric Validation

To validate whether gate scores correlate with human quality judgments:

1. Run all three gates on each report in blocking mode
2. Extract gate scores (QW verdict, MP verdict, RR verdict with taste dimensions)
3. Compute correlation between gate scores and human overall_quality
4. If correlation r > 0.7: gate composite is a valid optimization metric
5. If correlation r < 0.7: need to calibrate gate weights or use human annotations directly

### How to Add New Reports

1. Place report markdown in `evaluation-corpus/reports/{report-id}/report.md`
2. Place transcript in `evaluation-corpus/reports/{report-id}/transcript.md`
3. Copy `evaluation-corpus/templates/annotation-template.md` to `evaluation-corpus/reports/{report-id}/annotation.md`
4. Fill in all dimensions and PBW flags
5. Update this README with new summary row
6. Run `evaluation-corpus/scripts/compute-correlation.ts` to update metrics
