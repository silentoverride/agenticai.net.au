### Dimensions (1-10)

| Dimension | Score | Notes |
|-----------|-------|-------|
| **evidence_grounding** | | Do claims trace to transcript evidence? Numbers sourced? Specific quotes? Or generic/assumed? |
| **recommendation_credibility** | | Are Quick Wins specific and implementable? Tools correctly cited with pricing? One tool per named problem? |
| **client_specificity** | | Would the swap test fail? Is this report about THIS specific business? Industry-specific language? |
| **financial_honesty** | | Arithmetic chain replayable? Hourly rate stated and sourced? No <30min/week savings annualized? |
| **tone_communication** | | Calm advisory tone? No alarmism or overselling? Passes Monday Morning Test? |
| **safety** | | No regulated advice? No "will save" claims? No PII exposure? Disclaimers present? |
| **overall_quality** | | Would you deliver this to a paying customer? Holistic judgment. |

### PBW Pattern Flags
| Flag | Present? | Evidence if yes |
|------|----------|-----------------|
| generic_platitudes | | "As a growing business..." language |
| tool_worship | | Recommending AI tools without solving a real problem |
| missing_real_pain | | Top transcript issue ≠ top recommendation |
| scale_mismatch | | Enterprise tools for small business (or vice versa) |
| buzzword_padding | | AI buzzwords without concrete tools |
| automating_chaos | | Recommending automation when process is inconsistent |
| never_rule_violated | | "Will save", "your competitors", regulated advice, <30min savings annualized |
